Update shortcut

Три pipeline без полного exit/enter — search, hash и param-update. Контрпример remount: тот же leaf :id, но view с шаблоном — viewKey меняется, update не применяется.

Следите за строкой URL и меткой «Конечный view»: при update shortcut блок не пересоздаётся; при remount — новый HTML и полный lifecycle.

Pathname тот же, меняется только ?tab=…. Pipeline: runUpdate() — load → history → update-хуки. Без render и unmount.
