prefetch="intent" на <aura-router>

Prefetch

Роутер по умолчанию подгружает контент при наведении на in-app ссылки (intent). Переопределение — атрибут data-prefetch на ссылке.

Откройте «Конфиг» в шапке и смотрите журнал: при prefetch и загрузке loader появятся записи.

Цель — медленный loader (~1.4 s)

intent (наведение) data-prefetch не задан — наследует router
Медленная страница
tap (клик) data-prefetch="tap"
Только по клику
выключен data-prefetch="false"
Без prefetch
HTML с сервера (preserve view) ← Dev-хаб
