Вложенные маршруты

Родительский layout содержит внутренний outlet: оболочка сохраняется, меняется только вложенный view.

Синяя рамка — layout, зелёная пунктирная область — вложенный outlet, зелёный блок — конечный view.

Layout и вложенный outlet

Маршрут с атрибутом layout рендерит шаблон с собственным <aura-outlet>. Дочерние маршруты монтируют view во внутренний outlet. При переходе «User 1» → «User 2» layout остаётся в DOM, обновляется только содержимое slot.

Index-дочерний маршрут (path=".")

Точка (path=".") задаёт view по умолчанию для ветки. URL остаётся /users — без дополнительного сегмента и без редиректа.

/users /users/1

Переключение sibling-маршрутов

Список и профиль пользователя — sibling-маршруты под одним layout. При переключении между ними layout не размонтируется: происходит смена только конечного view во вложенном outlet.

Динамический сегмент :id

Один view обслуживает произвольный идентификатор в path. Переход User 1 → User 2 — обновление (update) того же маршрута: layout стабилен, меняются параметр id и URL.
