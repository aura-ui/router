Продвинутые сценарии

Приоритет сопоставления URL, многоуровневая вложенность layout и declarative catch-all для 404.

Синий — layout L1, фиолетовый — layout L2, слот + <aura-outlet> — зона монтирования, зелёный блок — конечный view.

Приоритет маршрутов

При нескольких кандидатах побеждает более специфичный pattern: статический сегмент → динамический :id → catch-all *.

Третий уровень вложенности

Цепочка outlet: корневой → users-layout → user-layout → конечный view. Профиль и настройки одного пользователя разделяют layout второго уровня.

Catch-all и 404

Маршрут path="*" обрабатывает path, для которого нет более специфичного совпадения. URL в адресной строке сохраняется; страница не перезагружается.
