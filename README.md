# Aura UI Router

SSR-first router for [Aura UI](https://aura-ui.dev) — a **Web Components** platform with declarative routes in HTML, predictable lifecycle hooks, and seamless SPA transitions after hydration.

```bash
npm install @aura-ui-web/router
```

### What `web` means in `@aura-ui-web`

In the Aura UI npm scope, **`web` stands for Web Components** — the first word of the technology we target (`Web Components`), not a generic “web app” label and not a development/pre-release channel.

```
Web Components  →  web  →  @aura-ui-web/router
```

Example packages:

```
@aura-ui-web/router
@aura-ui-web/base
@aura-ui-web/components   (planned)
```
