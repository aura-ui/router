Анимации: fade

Плоские маршруты с пакетом transition="fade". Выберите transition-order в панели над outlet — затем переключайтесь A ↔ B и сравните поведение.

Розовая рамка — корневой <aura-outlet>. При parallel в outlet на время перехода два [data-aura-view-root]; при out-in сначала исчезает старый view, потом появляется новый.

transition-order

Атрибут на <aura-router> задаёт порядок фаз transitionOut и transitionIn. Кнопки в панели URL меняют значение на лету — следующая навигация уже с новой политикой.

  • parallel — crossfade: outgoing и incoming одновременно в outlet
  • out-in — сначала fade-out, затем fade-in
  • in-out — incoming монтируется в stage, fade-in, затем fade-out outgoing

Текущий режим: parallel

Хук fade

Core не содержит встроенных анимаций — только фазы pipeline и staged mount. Хук fade анимирует [data-aura-view-root] на фазах transitionOut / transitionIn. При prefers-reduced-motion анимация пропускается.
